# KIND 2026-09-26 블로그 글 — 올리는 법

파일은 플랫폼·언어마다 세 가지가 있습니다.
- `<플랫폼>_<언어>.html`: 브라우저로 열어 보는 미리보기. 복사용으로도 씁니다.
- `<플랫폼>_<언어>_paste.html`: HTML 모드에 그대로 붙여넣는 본문입니다.
- `<플랫폼>_<언어>.meta.json`: 제목, 슬러그, 요약(검색 설명), 태그, 카테고리, 대표 이미지 주소가 들어 있습니다.

| 플랫폼 | 파일 | 올리는 법 |
|---|---|---|
| WordPress (한·영·일) | `wordpress_*_paste.html` | 새 글 → 블록 추가 '사용자 정의 HTML'에 붙여넣기 → 메타의 제목·슬러그·요약·태그 입력 → 대표 이미지 설정 |
| AdSense 블로그 / Blogger (한·영·일) | `adsense_*_paste.html` | 새 글 → 'HTML 보기'에 붙여넣기 → '검색 설명'에 `search_description` → 라벨에 태그. 본문 속 `<!-- ▼ AdSense … -->` 자리는 게시물 내 광고 위치 |
| Tistory (한) | `tistory_kr_paste.html` | 글쓰기 → 기본모드 옆 'HTML' 선택 → 붙여넣기 → 태그 입력 |
| Naver 블로그 (한) | `naver_kr.html` | 브라우저로 열기 → Ctrl+A, Ctrl+C → 스마트에디터에 Ctrl+V(사진은 네이버가 자동으로 올림) → 태그 10개 |
| Substack (한·영·일) | `substack_*.html` | 브라우저로 열기 → 제목 아래 본문만 복사 → 새 글에 붙여넣기 → 부제는 메타의 `subtitle` |
